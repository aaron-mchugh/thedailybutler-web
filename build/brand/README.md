# Canonical channel mark

`channel-logo.webp` is a 360px transparent derivative of the exact Daily Butler
logo used in Aaron's approved Butler Library banner. It is retained here so the
website does not require the legacy repository at build time. No lettering or
artwork was generated or redesigned.

Original source (read-only reference):
`daily-saints/assets/branding/logo_e_synthwave_premium_transparent.png`

Original SHA-256:
`3943689250dcd7ce9ab81af925b2fbabdb912e3f99f1252ed2008957095c1bc0`

The site uses the current `the-daily-butler/assets/brand/banner.png`, selected by
Aaron on 17 September 2026, and published episode thumbnails. Original assets
are left intact. Image sources, attribution, and review metadata are retained in
`build/asset-provenance.json`. The `build` directory is excluded from deployment.
