# The Daily Butler — website

Static site for **thedailybutler.com**: the podcast + video home and a full
**online reader** for Butler's Lives of the Saints (1894, public domain).

Auto-generated by `build/build.py` from the daily-saints pipeline + the Butler corpus.
Each episode page, home/archive/about, and all 366 reader pages are committed as
static HTML; **Vercel deploys them straight from this repo** — no build step on Vercel.

## Layout

```
build/build.py        the generator (run locally; see below)
build/css/site.css    source CSS (copied to /css/ by the build)
build/js/site.js      source JS (newsletter form, archive search) → /js/
api/subscribe.js      Vercel serverless function: POST /api/subscribe → Resend
vercel.json           static rewrites + cache headers + function config
css/ js/              generated (committed)
index.html            home
archive/index.html    searchable episode archive
about/index.html      about
subscribe/index.html  newsletter page
episode/<date>/index.html   per-episode (video + audio + notes + read link)
reader/<MM-DD>/index.html   online reader (year-independent; 366 pages)
sitemap.xml robots.txt 404.html
```

## Data sources (read by the build on the machine that runs it)

- `~/AI/daily-saints/episodes/<date>/podcast.json` — episode metadata
- `~/AI/daily-saints/registry/<date>_storyboard.json` — hero art = **first shot**
  (authoritative; correctly picks the right saint's artwork)
- `~/AI/daily-saints/assets/branding/` — logo (favicon source)
- `~/books/butler-saints/butler-complete.md` — the source text (366 day-sections)

## Build & deploy

```bash
# from this repo root
python3 build/build.py                # generate the site into ./ (committed)
python3 build/build.py --upload-art   # also push new hero art to R2 (public)
git add -A && git commit -m "site: <date>" && git push
# → Vercel auto-deploys the static files to thedailybutler.com
```

The nightly pipeline appends this step **after** the podcast R2 sync, so a new
episode + its reader page go live each morning automatically.

### Hero art on R2
Episode artwork is uploaded to `feed.thedailybutler.com/art/<date>.jpg`
(public) by `--upload-art`. The site references those URLs. If you add episodes
without running `--upload-art`, the episode page falls back to the cover art.

## Vercel env vars (set in the project settings / dashboard)

| Var | Value |
|---|---|
| `RESEND_API_KEY` | your Resend API key |
| `RESEND_AUDIENCE_ID` | `9fda8618-5b83-4763-8ee1-4620bad0cf7c` (audience "thedailybutler") |

`/api/subscribe` adds the submitted email to that audience (422 = already
subscribed, treated as success). Fails closed if the vars are missing.

## Domain

`thedailybutler.com` (Cloudflare) points at Vercel via the A/CNAME records
Vercel shows after the domain is attached.

## Design

Synthwave identity (matches the video brand): dark violet→magenta gradient,
chrome BUTLER wordmark, striped-sun motif, neon-pink accents. The **reader pane**
is the deliberate contrast: warm serif on parchment, framed by the synthwave
chrome, so the 1894 text reads like a book.
